# Agents

These style guides document only **non-standard, opinionated choices**. Do not
add guidelines that restate widely accepted best practices, language defaults,
or conventions already enforced by the configured linters and type checkers.

Before adding a guideline, ask: would a competent developer working in this
language already do this without being told? If yes, leave it out.
